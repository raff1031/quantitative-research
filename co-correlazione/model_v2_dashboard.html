v2 Architecture

  • GARCH(1,1) Fitted per asset. Captures volatility clustering and gives a true conditional sigma_t for tomorrow. Replaces naive rolling std.
  • DCC-EWMA Engle (2002) Dynamic Conditional Correlation via GARCH-standardised residuals + RiskMetrics EWMA (lambda=0.94). Predicts tomorrow's correlation matrix.
  • HMM 3-state Gaussian Hidden Markov Model on IBB returns + GARCH vol. Detects latent regime: Bear / Sideways / Bull. Used as meta-feature and for regime-aware signals.
  • PCA Rolling 63-day PCA to decompose returns into systematic factor (PC1) and per-asset idiosyncratic residual. Idio = alpha signal, PC1 = beta signal.
  • Walk-Forward Expanding window: retrain every 21 trading days using all past data. Zero lookahead bias. Mimics production deployment.
  • Calibration Platt scaling (sigmoid) wraps GBM. Raw GBM scores are not true probabilities — calibration fixes this so P(UP)=70% really means 70%.
