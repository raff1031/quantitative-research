How it works

  • Features Rolling correlations (10d/21d/63d), realized vol, vol-of-vol, momentum (1d…21d), cross-asset divergence spreads, correlation regime flag

  • Signal P(UP tomorrow) > 0.5 → Long, else Short
  • Validation Walk-forward: predictions generated only on remaining 35% (out-of-sample) — no lookahead bias
  • Backtest 1-day holding period, no transaction costs, Long/Short on signal
